## 🆘 Aide Immédiate

### Le formulaire ne s'affiche pas ?
1. Vérifiez l'URL : `/admin/products/new`
2. Rechargez la page (Ctrl + R)
3. Vérifiez la console (F12)

### Images ne se chargent pas ?
```
✓ Format accepté : JPG, PNG, WebP, GIF
✓ Taille max : 5 Mo
✓ Plusieurs images simultanées OK
```

### Slug ne se génère pas ?
```
✓ Tapez d'abord le nom
✓ Le slug apparaît automatiquement
✓ Vous pouvez le modifier manuellement
```

### Marge affichée incorrectement ?
```
✓ Prix de vente > Prix d'achat
✓ Remplissez les deux prix
✓ Calcul automatique après saisie
```
